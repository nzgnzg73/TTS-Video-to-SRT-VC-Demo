### Step 1: TTS English (انگریزی زبان کا ماڈل)

| خصوصیت | تفصیل |
|:---|:---|
| **زبان** | صرف انگلش |
| **سپیڈ** | CPU اور GPU دونوں پر بہترین |
| **وائس کلوننگ** | جی ہاں، فل کنٹرول کے ساتھ |

**کنٹرول پٹیاں (Sliders):**

| پٹی | ڈیفالٹ | کام |
|:---|:---:|:---|
| `Temperature` | 0.8 | آواز کا لہجہ بدلتا ہے |
| `Exaggeration` | 0.5 | جذبات کم یا زیادہ کرتا ہے |
| `CFG Weight` | 0.5 | آواز کی کوالٹی کنٹرول |
| `Speed Factor` | 1.0 | بولنے کی رفتار تیز/آہستہ |
